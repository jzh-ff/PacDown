# PacDown 技术架构文档

> 全平台视频下载工具 · v1.1 · 2026-08

## 1. 系统概览

PacDown 是一个本地运行的 Web 应用：粘贴视频链接 → 自动识别平台 → 解析无水印源 → 队列下载 → 元数据双份保存；支持合集/分P/主页批量、订阅博主自动追更、视频/图片后处理工具箱与通知中心。

```
┌────────────────────────────────────────────────────────┐
│  浏览器（static/ 单页应用）                              │
│  下载 · 片库 · 订阅 · 工具箱 · 搬运 · 设置（明暗双主题） │
└──────────────┬─────────────────────────────────────────┘
               │ HTTP / JSON（轮询进度）
┌──────────────▼─────────────────────────────────────────┐
│  FastAPI (app/main.py)                                  │
│  parse / download / tasks / history / collection /      │
│  toolbox / notifications / config / subs / repost       │
├────────────────────────────────────────────────────────┤
│  DownloadManager (downloader.py)                        │
│  worker × N 原子认领 → 进度回调 → 后处理 → 落盘          │
├───────────┬───────────┬───────────┬────────────────────┤
│ Parsers    │ toolbox   │ scheduler │ postprocess        │
│ 插件层     │ ffmpeg/   │ APScheduler│ MP3/弹幕/截帧     │
│            │ Pillow    │ 四平台订阅 │                    │
├───────────┴───────────┴───────────┴────────────────────┤
│  SQLite (data/metadata.db)  ·  config.json              │
└────────────────────────────────────────────────────────┘
```

## 2. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python 3.10+ / FastAPI / uvicorn | 单进程 + 线程池并发下载 |
| 通用引擎 | yt-dlp | B站解析下载 + m3u8 + 上千站点兜底 |
| HTTP 客户端 | httpx | 平台直连解析（支持 http2、代理） |
| 定时任务 | APScheduler | 订阅追更（默认 30 分钟） |
| 媒体处理 | ffmpeg / Pillow | 转码、剪辑、GIF、图片转换与拼接 |
| 前端 | 原生 HTML/CSS/JS | 无构建、离线可用；CSS 变量双主题 |
| 存储 | SQLite + JSON sidecar | 数据库查询 + 文件级迁移各取所长 |

## 3. 模块设计

### 3.1 解析器插件（app/parsers/）

所有解析器继承 `Parser` 基类，通过 `@register` 装饰器注册到注册表。`dispatch(url)` 按 `can_parse()` 匹配；都不命中则回落 `generic`（yt-dlp 引擎）。

**统一数据模型 `VideoInfo`**：platform、video_id、title、author、cover、duration、publish_time、stats、quality_options、images（图集）、raw（原始数据，写入 sidecar）。

| 文件 | 平台 | 解析路径 |
|---|---|---|
| bilibili.py | B站 | yt-dlp `extract_info` 解析 + 下载；网页 view API 补充数据；`?p=N` 分P独立 id；`list_related()` 列出分P/合集 |
| douyin.py | 抖音 | **双路径**：① Cookie + PC SSR 数据流提取 playAddr ② iesdouyin 分享页（免配置）；`list_mix()` 合集列表（双路径）；单视频带合集入口 |
| kuaishou.py | 快手 | 短链重定向 → 页面 `__NEXT_DATA__`/videoData 挖掘 photo.mainMvUrls |
| xiaohongshu.py | 小红书 | note 页 `__INITIAL_STATE__` 提取视频流/图集（通常需 Cookie） |
| direct.py | 直链/m3u8 | 扩展名/`#direct` 锚点识别；HEAD 探测元信息；断点续传（.part + Range）；m3u8 走 yt-dlp |
| generic.py | 通用 | yt-dlp 引擎（YouTube、西瓜、微博等上千站点） |
| ytdlp_engine.py | — | yt-dlp 封装：cookie 文件、进度 hook、清晰度、自定义 Referer |
| http_download.py | — | httpx 流式下载（支持断点续传）、短链重定向、内嵌 JSON 提取、Referer 表 |

**去水印原理**：抖音/快手解析的是平台无水印源地址（playAddr / mainMvUrls），下载即无水印，非 AI 消除。B站视频本身无水印。

**直链锚点语法**：`url#direct;name=文件名.mp4;referer=https://...`，用于无扩展名链接强制直链、指定文件名与防盗链 Referer。

### 3.2 下载管道（app/downloader.py）

一条 `videos` 记录即一个任务（任务与历史同源）：

```
create_task: INSERT(parsing)
worker × N:  claim_task(parsing→working)   ← 原子认领，防多 worker 重复执行
             → parser.parse() → 去重检查(video_id) → pending
             → claim_task(pending→downloading) → parser.download()
             → processing → 封面（无平台封面时 ffmpeg 截帧兜底）
             → [弹幕] → [评论] → [MP3] → sidecar JSON → done
失败:        status=failed + error + 写入通知中心，可 retry
```

- 目录规则：`下载目录/平台/作者/`；文件名由 `name_template` 渲染（`{date} {title} {author} {platform} {id}`）
- 图集：逐张下载 `{标题}_{序号}.jpg`
- 进度回调 0.4s 节流写库；`claim_task` 用 UPDATE…WHERE status 原子抢占任务

### 3.3 合集 / 主页批量

`/api/parse` 按链接形态分发：
- **B站视频**：`list_related()` 顺带返回分P（pages>1）与合集（ugc_season）→ 前端可展开勾选
- **抖音合集页**：`list_mix()`（Cookie PC 合集页 SSR / ies mix/aweme 接口双路径）
- **抖音单视频**：parse 提取 mix_info → 前端「下载整个合集」按钮 → `GET /api/collection` 懒加载
- **博主主页**（space.bilibili.com / douyin.com/user）：复用订阅的 `fetch_uploader_videos()`，limit 50

### 3.4 订阅调度与自动清理（app/scheduler.py）

- B站空间列表：**wbi 签名直调 arc/search API**，失败（412 风控、code≠0）自动回退 **yt-dlp flat playlist**
- 抖音博主：主页 `_ROUTER_DATA` 挖掘 aweme 列表（需 Cookie，尽力而为）
- 小红书/快手博主：主页内嵌 JSON 挖掘（实验性，建议 Cookie）
- 每订阅 `options` 列可覆盖全局后处理（自动 MP3/弹幕）
- 比对库里 video_id，新视频自动入下载队列并写入通知中心
- **自动清理**：`auto_clean_once()` 每 24h 执行（启动 5 分钟后先跑一遍，即发版即生效）；按 `auto_clean_days` 删除超期的已完成视频（`downloaded_at` 判定，收藏默认保留）、工具产物与上传素材，清空残留目录并写通知

### 3.5 工具箱（app/toolbox.py）

- 任务落 `tool_jobs` 表，单线程串行执行（ffmpeg 重负载，避免抢占下载带宽）
- 进度：ffmpeg `-progress pipe:1` 解析 out_time；图片工具按张数推进
- 视频工具：转码（h264/h265/vp9/copy + 分辨率 + CRF）、压缩、剪辑（-c copy 无损）、GIF、文字水印（drawtext + 本机字体）、截帧
- 图片工具（Pillow）：格式转换/压缩、竖拼长图、图集打包 ZIP
- 素材来源：片库已完成记录（视频/图集）或本地上传（`data/uploads/`）
- 产物写入 `下载目录/_tools/`

### 3.6 数据模型

**videos**（任务+历史合一）：platform / video_id / title / author / cover / duration / publish_time / stats(JSON) / quality / file_path / file_size / audio_path / danmaku_path / images(JSON) / raw_json / status / progress / speed / error / options(JSON) / **tags(JSON)** / **favorite** / created_at / downloaded_at

**subscriptions**：platform / uploader_id / uploader_name / avatar / enabled / last_checked / last_error / new_count / **options(JSON)**

**notifications**：kind(subscription/task/system) / title / body / read / created_at

**tool_jobs**：kind / src(video:id | upload:name) / params(JSON) / status / progress / out_path / extra(JSON 多产物) / error / 时间戳

**Sidecar JSON**：与视频同目录，含全部元数据 + raw 原始数据，脱离数据库可迁移。

### 3.8 前端

- 单页应用：`index.html` + `css/design.css` + `js/app.js`，无构建、无外部 CDN（离线可用）
- 设计系统：CSS 变量双主题（暗色默认）、紫→蓝渐变、玻璃拟态（backdrop-filter）、等宽数字数据展示
- 签名元素：下载进度条流动光带（shimmer/slide 动画）
- 状态徽章呼吸灯、骨架屏、空状态、Toast、键盘 Esc 关闭、focus-visible、prefers-reduced-motion
- 进度获取：1.5s 轮询 /api/tasks + /api/notifications（本地场景足够，无 SSE 复杂度）
- 批量解析结果：sections 结构（分P/合集/主页）统一渲染，子项独立勾选
- 全局 `[hidden] { display:none !important }`：防止组件 display:flex 覆盖 hidden 属性

## 4. 风控与对策（重要）

平台风控持续收紧，本工具的对策分层：

| 风险 | 对策 |
|---|---|
| 抖音公开通道关闭（2025+） | Cookie 路径为主 + 免 cookie 兜底 + 失败时 UI 给出 Cookie 配置指引 |
| 小红书强风控 | 解析器隔离，Cookie 可配，错误信息明确 |
| B站空间 API 412 | wbi 签名（code≠0 视为失败）+ yt-dlp 双路径自动回退 |
| 任意平台接口变化 | 解析器单文件隔离，改动不影响其他平台 |
| 高清限制 | B站 1080P+ 需 SESSDATA；清晰度请求失败自动回退 best |
| 网盘无公开通道 | 直链下载器 + 锚点指定 Referer，配合浏览器直链插件使用 |

## 5. 安全与合规

- 仅监听 127.0.0.1（Docker 模式 0.0.0.0 由用户自行暴露）
- Cookie 只存本机 config.json，API 回显打码（`__SET__`/`__KEEP__` 占位）
- 上传文件按扩展名白名单 + 文件名安全化，上传与文件服务均防目录遍历
- 仅供个人学习与备份已授权内容，请勿用于批量爬取与分发
