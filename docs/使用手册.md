# PacDown 使用手册

> 全平台视频下载工具 · 下载 B站 / 抖音 / 快手 / 小红书 / YouTube 等平台视频，无水印保存

## 1. 启动

### Windows 一键启动
双击 `start.bat`（首次运行自动创建虚拟环境并安装依赖），浏览器打开：

```
http://127.0.0.1:8300
```

### 手动启动
```bash
pip install -r requirements.txt
python run.py
```

### Docker 部署（NAS / 服务器）
```bash
docker compose up -d
```
下载的视频在 `./downloads`，数据库在 `./data`，配置在 `./config/config.json`。

## 2. 下载视频（核心用法）

1. 在「下载」页粘贴链接，三种方式都可以：
   - 直接粘贴视频页链接，如 `https://www.bilibili.com/video/BV1xxxx`
   - 粘贴分享短链，如 `https://v.douyin.com/xxxxx/`
   - **整段复制分享文案**（"快看这个视频，太搞笑了 https://v.douyin.com/xxxx 复制此链接…"）——工具会自动提取里面的所有链接
2. 点击 **解析链接** → 显示每个视频的封面、标题、作者、播放量、清晰度
3. 可勾选/取消勾选，点 **开始下载**（可先勾选「提取 MP3」「下载弹幕」）
4. 下方实时显示进度条与速度；失败的任务可点 **重试**

**批量**：一次最多 50 个链接，每行一个或混在文案里都行。

**切换保存位置**：输入框下方显示当前目录，点击可选最近用过的目录；也可在「设置」页修改。

**文件保存结构**：
```
downloads/
└── bilibili/
    └── UP主名/
        ├── 20240101_视频标题.mp4      ← 视频
        ├── 20240101_视频标题.xml      ← 弹幕（勾选时）
        ├── 20240101_视频标题.mp3      ← 音频（勾选时）
        ├── 20240101_视频标题_cover.jpg ← 封面
        └── 20240101_视频标题.json     ← 完整元数据
```

**去重**：已下载过的视频再次提交会提示"已存在"，不会重复下载（想强制重下可在历史详情点「重新下载」）。

## 3. 查看与管理（历史页）

- **统计概览**：视频总数、占用空间、今日新增、失败数、各平台分布
- **搜索与筛选**：按标题/作者搜索，按平台、状态筛选
- **详情**：点击卡片查看全部元数据（播放/点赞/收藏、发布时间、文件路径），可展开原始 JSON
- **操作**：打开文件所在目录、重新下载、删除记录（默认保留文件）、导出 CSV

## 4. 搬运工作台（搬运页）

把已下载的视频准备成"可发布"状态——AI 改写文案、标注原作者、一键复制：

1. **配置 AI**（一次性）：设置 → AI 文案 → 填 API 地址与 Key。推荐智谱 `glm-4-flash`（免费），也支持 DeepSeek、OpenAI 等兼容接口
2. 左侧列表选择要搬运的视频（可搜索），右侧显示原标题与原文案
3. 选择文案风格（自然口语 / 爆款吸睛 / 精简两句话 / 讲故事），勾选是否「标注原作者」
4. 点 **AI 生成文案** → 得到新标题、新文案、5-8 个流量标签，全部可手动编辑
5. **复制文案** 到剪贴板，**打开视频文件夹** 拿文件，去目标平台手动发布

- 「标注原作者」开启时，AI 会在文案末尾加一行 `转自抖音 · 某某某`
- 所有生成记录保留在下方「生成历史」，可随时再次复制
- **合规提醒**：发布前请确认已获得原作者授权；工具不会自动上传（自动发布违反平台协议且容易封号）

## 5. 订阅追更（订阅页）

1. 粘贴博主主页链接（B站：`https://space.bilibili.com/数字ID`；抖音：`https://www.douyin.com/user/xxx`）
2. 工具按设定的间隔（默认 30 分钟）自动检查新视频，发现即自动下载
3. 支持：手动检查、暂停/恢复、删除订阅；最近错误会显示在卡片上

## 6. 设置说明

| 设置项 | 说明 |
|---|---|
| 下载目录 | 视频保存位置，改后新任务生效 |
| 同时下载任务数 | 1–8，默认 3 |
| 默认清晰度 | `best` 为最高可用；也可填清晰度 ID |
| 订阅检查间隔 | 分钟，最小 5 |
| HTTP 代理 | 如 `http://127.0.0.1:7890`（访问 YouTube 等外网站点需要） |
| B站 Cookie（SESSDATA） | 解锁 1080P+/高码率，游客只能 480P |
| 抖音/快手/小红书 Cookie | 提高解析成功率，**抖音目前建议配置** |

## 7. Cookie 获取方法（一次性操作）

抖音、小红书解析失败时需要配置 Cookie（无需登录账号）：

1. Chrome/Edge 打开对应网站（如 `www.douyin.com`），随便浏览一下
2. 按 `F12` 打开开发者工具 → **网络（Network）** 标签 → 刷新页面
3. 点击第一个请求，在 **请求标头（Request Headers）** 里找到 `Cookie:` 一行
4. **完整复制** Cookie 值（很长，全部复制）→ 粘贴到 PacDown「设置 → 平台 Cookie」→ 保存

B站同理，或只复制 `SESSDATA=xxx` 字段（登录后的 SESSDATA 可解锁会员清晰度）。

## 8. 常见问题

**Q：抖音解析失败？**
2025 年起抖音关闭了免 Cookie 的公开解析通道。请在设置中配置抖音 Cookie（方法见上节），配置后基本稳定。

**Q：B站只能下 480P？**
未配置 SESSDATA 时游客权限只有 480P。设置中配置 B站 Cookie 即可解锁 1080P+（大会员内容需要大会员账号的 Cookie）。

**Q：MP3 提取失败？**
需要本机安装 [ffmpeg](https://ffmpeg.org/download.html) 并加入 PATH。Docker 版已内置。

**Q：YouTube 下不了？**
需要配置 HTTP 代理（设置页），并确保网络可达。

**Q：下载的文件在哪？**
下载页输入框下方显示当前目录；历史详情中可一键打开所在目录。

**Q：想搬移视频到别的电脑？**
直接拷贝 `downloads` 文件夹 + `data` 文件夹即可。每个视频旁的 `.json` 包含全部信息，脱离数据库也能看。
