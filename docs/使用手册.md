# PacDown 使用手册

> 全平台视频下载工具 · 下载 B站 / 抖音 / 快手 / 小红书 / YouTube 等平台视频，无水印保存 · v1.1

## 1. 启动

### Windows 一键启动
双击 `start.bat`（首次运行自动创建虚拟环境并安装依赖），浏览器打开：

```
http://127.0.0.1:8300
```

### 手动启动
```bash
pip install -r requirements.txt
python run.py
```

### Docker 部署（NAS / 服务器）
```bash
docker compose up -d
```
下载的视频在 `./downloads`，数据库在 `./data`，配置在 `./config/config.json`。

## 2. 下载视频（核心用法）

1. 在「下载」页粘贴链接，三种方式都可以：
   - 直接粘贴视频页链接，如 `https://www.bilibili.com/video/BV1xxxx`
   - 粘贴分享短链，如 `https://v.douyin.com/xxxxx/`
   - **整段复制分享文案**（"快看这个视频，太搞笑了 https://v.douyin.com/xxxx 复制此链接…"）——工具会自动提取里面的所有链接
2. 点击 **解析链接** → 显示每个视频的封面、标题、作者、播放量、清晰度
3. 可勾选/取消勾选，点 **开始下载**（可先勾选「提取 MP3」「下载弹幕」）
4. 下方实时显示进度条与速度；失败的任务可点 **重试**，也可用「重试全部失败」「清空失败/重复」批量管理

**批量**：一次最多 50 个链接，每行一个或混在文案里都行。

### 2.1 合集 / 分P / 主页批量下载

解析时自动识别以下链接并给出可勾选的批量列表：

| 链接形态 | 效果 |
|---|---|
| B站多分P视频 `…/video/BVxxx` | 展开「分P · 共 N 部分」，逐P勾选下载 |
| B站合集视频 | 展开「合集《xxx》· N 集」，整集勾选下载 |
| 抖音合集页 `douyin.com/collection/xxx` | 直接列出合集全部视频 |
| 抖音单视频（属于合集时） | 卡片上出现「展开下载全集」按钮，点击后拉取合集列表 |
| B站空间 `space.bilibili.com/xxx`、抖音主页 `douyin.com/user/xxx` | 列出博主最新 50 个视频，勾选批量下载 |

B站分P单独下载：链接带 `?p=N`（如 `…/video/BVxxx?p=3`）即按第 N 部分独立入库，标题为分P名。

### 2.2 直链与网盘下载

任意以媒体/文件扩展名结尾的 http(s) 链接（`.mp4 .mkv .mp3 .jpg .zip .m3u8` 等）会走「直链」通道下载，支持断点续传。

**网盘用法**：百度/夸克/阿里等网盘没有免登录下载通道，正确姿势是：
1. 用浏览器插件（如"网盘直链下载助手"类）或网盘官方客户端获取**真实下载地址**
2. 粘贴到 PacDown 下载——支持批量、断点续传，不走网盘限速通道

**高级**：链接后加锚点可强制直链通道并指定信息：
```
https://example.com/file?id=123#direct;name=我的视频.mp4;referer=https://example.com/
```
- `#direct`：无扩展名的链接强制按直链处理
- `;name=xxx`：指定保存文件名
- `;referer=xxx`：服务器有防盗链时附带 Referer

`.m3u8`（HLS 流）链接自动用 yt-dlp 合并下载为 mp4。

**切换保存位置**：输入框下方显示当前目录，点击可选最近用过的目录；也可在「设置」页修改。

**文件保存结构**：
```
downloads/
└── bilibili/
    └── UP主名/
        ├── 20240101_视频标题.mp4      ← 视频
        ├── 20240101_视频标题.xml      ← 弹幕（勾选时）
        ├── 20240101_视频标题.mp3      ← 音频（勾选时）
        ├── 20240101_视频标题_cover.jpg ← 封面（无平台封面时自动截帧生成）
        └── 20240101_视频标题.json     ← 完整元数据
```

文件名可按模板自定义：设置 → 文件命名模板，支持 `{date} {title} {author} {platform} {id}` 变量。

**去重**：已下载过的视频再次提交会提示"已存在"，不会重复下载（想强制重下可在历史详情点「重新下载」）。

## 3. 查看与管理（片库页）

- **统计概览**：视频总数、占用空间、今日新增、失败数、各平台分布
- **搜索与筛选**：按标题/作者/文案搜索，按平台、状态、**标签**、**收藏**筛选
- **视图切换**：网格 / 列表两种视图（列表视图信息更全，选择"不分组"时可用）
- **标签与收藏**：打开详情弹窗 → 点 ★ 收藏；点「+ 标签」打标签（可多个），便于分类筛选
- **批量管理**：点工具栏「管理」→ 勾选卡片 → 批量删除（可选同时删文件）/ 导出选中 CSV
- **详情**：点击卡片查看全部元数据（播放/点赞/收藏、发布时间、文件路径），可展开原始 JSON
- **保存到本机**：详情弹窗点「保存视频到本机」（单个视频）或「打包下载 ZIP」（视频/图集 + 封面 + 音频 + 弹幕 + 元数据全打包）——服务器部署时通过浏览器把文件拉回本地
- **操作**：打开文件所在目录、重新下载、删除记录（可选是否删文件）、导出 CSV

## 4. 工具箱（工具页）

对已下载的素材（或本地上传的文件）做后处理：

**视频工具**（需 ffmpeg）：转码（H.264/H.265/VP9/仅换封装）、压缩（CRF 调节）、剪辑（起止时间无损裁剪）、GIF 动图、文字水印、截帧

**图片工具**：格式转换/压缩（WebP/JPG/PNG）、拼接长图（多图竖拼）、图集打包 ZIP

用法：
1. 左侧选素材：视频素材 / 图集素材两个 Tab，或点「上传本地文件」
2. 右侧选工具、调参数，点「开始处理」
3. 下方任务列表看进度，完成后直接「下载」产物

产物保存在 `下载目录/_tools/`；图片工具可同时处理整个图集（逐张输出）。

## 5. 搬运工作台（搬运页）

把已下载的视频准备成"可发布"状态——AI 改写文案、标注原作者、一键复制：

1. **配置 AI**（一次性）：设置 → AI 文案 → 填 API 地址与 Key。推荐智谱 `glm-4-flash`（免费），也支持 DeepSeek、OpenAI 等兼容接口
2. 左侧列表选择要搬运的视频（可搜索），右侧显示原标题与原文案
3. 选择文案风格（自然口语 / 爆款吸睛 / 精简两句话 / 讲故事），勾选是否「标注原作者」
4. 点 **AI 生成文案** → 得到新标题、新文案、5-8 个流量标签，全部可手动编辑
5. **复制文案** 到剪贴板，**打开视频文件夹** 拿文件，去目标平台手动发布

- 「标注原作者」开启时，AI 会在文案末尾加一行 `转自抖音 · 某某某`
- 所有生成记录保留在下方「生成历史」，可随时再次复制
- **合规提醒**：发布前请确认已获得原作者授权；工具不会自动上传（自动发布违反平台协议且容易封号）

## 6. 订阅追更（订阅页）

1. 粘贴博主主页链接：
   - B站：`https://space.bilibili.com/数字ID`
   - 抖音：`https://www.douyin.com/user/xxx`
   - 小红书：`https://www.xiaohongshu.com/user/profile/xxx`（需 Cookie，实验性）
   - 快手：`https://www.kuaishou.com/profile/xxx`（实验性）
2. 添加时可勾选「自动 MP3」「自动弹幕」——该订阅的新视频自动应用这些后处理
3. 工具按设定的间隔（默认 30 分钟）自动检查新视频，发现即自动下载
4. 支持：手动检查、暂停/恢复、删除订阅；最近错误会显示在卡片上

## 7. 通知中心

侧边栏顶部的 🔔 显示未读数。订阅抓到新视频、任务失败时会收到通知；首次点开时授权浏览器通知后，即使页面在后台也能收到桌面提醒。

## 8. 设置说明

| 设置项 | 说明 |
|---|---|
| 下载目录 | 视频保存位置，改后新任务生效 |
| 同时下载任务数 | 1–8，默认 3 |
| 默认清晰度 | `best` 为最高可用；也可填清晰度 ID |
| 文件命名模板 | 支持 `{date} {title} {author} {platform} {id}` 变量 |
| 订阅检查间隔 | 分钟，最小 5 |
| 自动清理 | 开启后每天检查一次，删除超过保留天数的已完成视频/工具产物/上传素材；收藏默认保留。**服务器部署强烈建议开启**，防止磁盘占满 |
| HTTP 代理 | 如 `http://127.0.0.1:7890`（访问 YouTube 等外网站点需要） |
| B站 Cookie（SESSDATA） | 解锁 1080P+/高码率，游客只能 480P |
| 抖音/快手/小红书 Cookie | 提高解析成功率，**抖音目前建议配置** |

## 9. Cookie 获取方法（一次性操作）

抖音、小红书解析失败时需要配置 Cookie（无需登录账号）：

1. Chrome/Edge 打开对应网站（如 `www.douyin.com`），随便浏览一下
2. 按 `F12` 打开开发者工具 → **网络（Network）** 标签 → 刷新页面
3. 点击第一个请求，在 **请求标头（Request Headers）** 里找到 `Cookie:` 一行
4. **完整复制** Cookie 值（很长，全部复制）→ 粘贴到 PacDown「设置 → 平台 Cookie」→ 保存

B站同理，或只复制 `SESSDATA=xxx` 字段（登录后的 SESSDATA 可解锁会员清晰度）。

## 10. 常见问题

**Q：抖音解析失败？**
2025 年起抖音关闭了免 Cookie 的公开解析通道。请在设置中配置抖音 Cookie（方法见上节），配置后基本稳定。合集列表同理。

**Q：B站只能下 480P？**
未配置 SESSDATA 时游客权限只有 480P。设置中配置 B站 Cookie 即可解锁 1080P+（大会员内容需要大会员账号的 Cookie）。

**Q：MP3 提取失败 / 视频工具不可用？**
需要本机安装 [ffmpeg](https://ffmpeg.org/download.html) 并加入 PATH。Docker 版已内置。

**Q：YouTube 下不了？**
需要配置 HTTP 代理（设置页），并确保网络可达。

**Q：网盘链接解析失败？**
请确认粘贴的是**真实文件直链**（以 .mp4/.zip 等结尾，或带 `#direct` 锚点），而不是网盘分享页地址。分享页需要先用浏览器插件提取直链。

**Q：下载的文件在哪？**
下载页输入框下方显示当前目录；历史详情中可一键打开所在目录。

**Q：想搬移视频到别的电脑？**
直接拷贝 `downloads` 文件夹 + `data` 文件夹即可。每个视频旁的 `.json` 包含全部信息，脱离数据库也能看。
