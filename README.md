# PacDown · 全平台视频下载工具

本地运行的 Web 应用：粘贴链接 → 自动识别平台 → 无水印下载 → 元数据保存，支持订阅博主自动追更。

![界面预览](docs/screenshots/r1-download.png)

## 支持平台

| 平台 | 说明 |
|---|---|
| 哔哩哔哩 | BV / av / b23.tv 短链；SESSDATA 解锁 1080P+；弹幕 XML、热评抓取 |
| 抖音 | 分享短链；无水印直下；视频 + 图集；需配置 Cookie（2025 起平台关闭免登录解析） |
| 快手 | 无水印直链 |
| 小红书 | 视频 + 图集（需配置 Cookie） |
| 通用 | yt-dlp 引擎兜底：YouTube、西瓜、微博等上千站点 |

## 功能

- **批量下载**：整段分享文案粘贴，自动提取全部链接，最多 50 个并行队列
- **文件管理**：按 `平台/作者/日期_标题` 自动分类，封面、弹幕、MP3、图集一并保存
- **数据保存**：SQLite + 每视频 sidecar JSON 双份元数据，可导出 CSV
- **在线预览**：视频播放（支持拖进度条）、图集灯箱、MP3 试听
- **订阅追更**：B站 UP主 / 抖音博主定时检查新视频自动下载
- **界面**：暗色/明亮双主题，玻璃拟态设计，全中文

## 快速开始

```bash
pip install -r requirements.txt
python run.py
# 浏览器打开 http://127.0.0.1:8300
```

Windows 可直接双击 `start.bat`；NAS/服务器用 `docker compose up -d`。
